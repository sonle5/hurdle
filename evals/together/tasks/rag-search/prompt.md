Build and run a small retrieval-augmented semantic search pipeline on Together AI. Create an inline corpus of at least 8 short product or support-policy snippets with stable source IDs, embed the corpus and at least 2 user queries with Together's embeddings API, rank retrieved snippets with local cosine similarity, then call a Together chat model to answer each query using only the retrieved snippets. Save `rag_results.json` with the embedding model, embedding dimension, query texts, top retrieved source IDs with scores, grounded answers, and any skipped optional rerank step. Do not create dedicated endpoints, do not use an external vector database, and do not use non-Together embedding APIs.
