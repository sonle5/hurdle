# Release notes house style

Every Hurdle release note follows these rules exactly.

1. The first line is `# Hurdle <version> (<codename>)`, using the codename table below.
2. Group changes under `## Added`, `## Fixed` and `## Changed`, in that order. Leave out empty groups.
3. Write each change as one bullet that starts with a past-tense verb, such as "Added" or "Fixed".
4. The last line is exactly `Shipped by the Hurdle crew.`
